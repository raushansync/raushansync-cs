Interactive SQL Lab: Subqueries & DML

Put your knowledge of nested queries, existential logic, and data manipulation to the test. This environment contains a complete mock database for a research organization.

Your Lab Tasks

The database contains four tables: divisions, staff, initiatives (projects), and staff_assignments. Solve the following scenarios:

  1. Set Membership (IN): Find the names of staff who are currently assigned to an initiative that has a budget of over $100,000. (Requires nesting subqueries!)
  2. Set Comparison (ALL): Write a query to find the name and salary of the highest-paid staff member without using the MAX() function. Use the >= ALL trick.
  3. Test for Empty Relations (NOT EXISTS): We suspect a division is completely inactive. Find the div_name of any division that currently has zero initiatives associated with it.
  4. Common Table Expressions (WITH): Calculate the average salary per division. Then, write a query using a WITH clause to list the div_name of divisions where the average salary is strictly greater than $80,000.
  5. Scalar Subqueries: Generate a report listing the title of every initiative alongside a dynamically computed column called team_size (the count of staff assigned to that specific initiative).
  6. Atomic Updates (CASE): Due to budget restructuring, update the staff table: Give a 10% raise (multiply by 1.10) to anyone earning under $75,000, and a 5% raise to everyone else. Use a single UPDATE with a CASE statement. (Run SELECT * FROM staff; afterward to check your work).
  7. Safe Deletion: Clean up the database by deleting any initiatives that currently have NO staff members assigned to them.

Task 1: Subquery with IN

SELECT name FROM staff
WHERE staff_id IN (
    SELECT staff_id FROM staff_assignments
    WHERE init_id IN (
        SELECT init_id FROM initiatives WHERE budget > 100000
    )
);

Task 2: Set Comparison (ALL)

Hint: If someone's salary is >= EVERY salary in the table, they must be the highest earner.

SELECT name, salary FROM staff
WHERE salary >= ALL (
    SELECT salary FROM staff
);

Task 3: Test for Empty Relations (NOT EXISTS)

SELECT div_name FROM divisions D
WHERE NOT EXISTS (
    SELECT * FROM initiatives I
    WHERE I.div_id = D.div_id
);

Task 4: The WITH Clause

WITH DivAverages(div_id, avg_sal) AS (
    SELECT div_id, AVG(salary)
    FROM staff
    GROUP BY div_id
)
SELECT D.div_name
FROM divisions D, DivAverages DA
WHERE D.div_id = DA.div_id AND DA.avg_sal > 80000;

Task 5: Scalar Subqueries

SELECT title, 
       (
           SELECT COUNT(*) 
           FROM staff_assignments SA 
           WHERE SA.init_id = I.init_id
       ) AS team_size
FROM initiatives I;

Task 6: UPDATE with CASE

Hint: Run the UPDATE statement, then run a SELECT statement separately to see the changes.

UPDATE staff
SET salary = CASE
    WHEN salary < 75000 THEN salary * 1.10
    ELSE salary * 1.05
END;

Task 7: DELETE

DELETE FROM initiatives
WHERE init_id NOT IN (
    SELECT init_id FROM staff_assignments
);
