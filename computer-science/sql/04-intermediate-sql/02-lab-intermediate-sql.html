Interactive SQL Lab: Joins & Views

Put your knowledge of relational combinations and virtual tables to the test. This environment contains a complete mock database for a retail inventory system.

Your Lab Tasks

The database contains four tables: categories, products, suppliers, and product_suppliers. Solve the following scenarios:

  1. Inner Join: Retrieve a list of all product names alongside their corresponding cat_name (category name).
  2. Left Outer Join: We need to audit our supply chain. List all product names and their sup_ids. Make sure to include products that currently have no supplier.
  3. Full Outer Join: Write a query to find ALL suppliers and ALL products. We want to spot suppliers that provide us nothing, and products that lack suppliers in one query. Select name (product) and sup_name.
  4. Creating a View: Create a view named premium_catalog that stores the prod_id, name, and price of all products where the price is strictly greater than $50. (Run a SELECT * on the view after creating it to test).
  5. Querying Views with Joins: Using your newly created premium_catalog view, join it with the categories table to display the product name and cat_name for these premium items.
  6. Views with Aggregation: Create a view called category_metrics that computes the total number of products (product_count) and the average price (avg_price) for each cat_id.

Task 1: Inner Join

SELECT p.name, c.cat_name
FROM products p
INNER JOIN categories c ON p.cat_id = c.cat_id;

Task 2: Left Outer Join

Hint: Put the products table on the left side of the join to preserve all products.

SELECT p.name, ps.sup_id
FROM products p
LEFT OUTER JOIN product_suppliers ps ON p.prod_id = ps.prod_id;

Task 3: Full Outer Join

SELECT p.name, s.sup_name
FROM products p
FULL OUTER JOIN product_suppliers ps ON p.prod_id = ps.prod_id
FULL OUTER JOIN suppliers s ON ps.sup_id = s.sup_id;

Task 4: Creating a View

CREATE VIEW premium_catalog AS
SELECT prod_id, name, price
FROM products
WHERE price > 50;

-- To test it:
SELECT * FROM premium_catalog;

Task 5: Querying Views with Joins

Hint: You need to link back to the products table to get the cat_id before joining categories, OR include cat_id in your view.

SELECT pc.name, c.cat_name
FROM premium_catalog pc
JOIN products p ON pc.prod_id = p.prod_id
JOIN categories c ON p.cat_id = c.cat_id;

Task 6: Views with Aggregation

CREATE VIEW category_metrics(cat_id, product_count, avg_price) AS
SELECT cat_id, COUNT(*), AVG(price)
FROM products
GROUP BY cat_id;

-- To test it:
SELECT * FROM category_metrics;
