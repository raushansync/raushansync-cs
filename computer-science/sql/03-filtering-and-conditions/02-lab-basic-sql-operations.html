Interactive SQL Lab: Basic Operations

Bridge the gap between basic retrieval and expressive relational queries. Practice pattern matching, formatting outputs, and foundational join concepts.

Your Lab Tasks

The database is pre-loaded with two tables from a corporate schema: employees and projects. Run your queries one by one in the editor below:

  1. The Cartesian Product: Let's see multiset semantics in action. Select everything from both tables: SELECT * FROM employees, projects;
    Observe the huge number of rows! Notice how every employee is paired with every project record.
  2. Equi-Join: Now fix the Cartesian product explosion by adding a WHERE clause that matches the emp_id from employees to the emp_id in projects. Select the employee's name and the project_code.
  3. Pattern Matching (LIKE): Query the employees table to find all employees whose name contains the letter 'a' (case-sensitive) and who work in the 'Engineering' department.
  4. Ordering & Limiting: Write a query to find the top 2 highest-paid employees. You will need to use ORDER BY and LIMIT (or FETCH FIRST).
  5. Advanced Predicates (BETWEEN & IN): Find the names, salaries, and departments of employees who earn between 65000 and 90000 AND belong to either the 'Marketing' or 'Data Science' departments.

Task 1: The Cartesian Product

SELECT * FROM employees, projects;

Task 2: Equi-Join

Hint: Filter the Cartesian product using the primary/foreign key relationship.

SELECT name, project_code 
FROM employees, projects 
WHERE employees.emp_id = projects.emp_id;

Task 3: Pattern Matching (LIKE)

Hint: Use %a% to match 'a' anywhere in the string.

SELECT * FROM employees 
WHERE name LIKE '%a%' AND department = 'Engineering';

Task 4: Ordering & Limiting

Hint: Sort by salary descending, then limit the output.

SELECT * FROM employees 
ORDER BY salary DESC 
LIMIT 2;

Task 5: Advanced Predicates

SELECT name, salary, department 
FROM employees 
WHERE salary BETWEEN 65000 AND 90000 
AND department IN ('Marketing', 'Data Science');
