Interactive SQL Lab: DDL Commands

Consolidate your understanding of schema structure. Write and execute Data Definition Language commands securely in your browser.

Your Lab Tasks

Run your queries one by one in the editor below to complete the challenges for a Library schema:

  1. CREATE: Create a new table named books with the following columns:
    book_id INT PRIMARY KEY, title VARCHAR(100), and pages INT.
  2. ALTER (Add): Add a new column to your table: ALTER TABLE books ADD published_year INT;
  3. ALTER (Drop): Remove the pages column: ALTER TABLE books DROP COLUMN pages;
  4. RENAME: Change the table name: ALTER TABLE books RENAME TO archives;
  5. TRUNCATE & DROP: The database has a pre-loaded table named visitor_logs with 3 rows.
    • Run SELECT * FROM visitor_logs; to see the data.
    • Run TRUNCATE TABLE visitor_logs; then select again to see that the structure remains but data is gone.
    • Run DROP TABLE visitor_logs; to completely destroy the table object.
