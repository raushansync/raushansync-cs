After This Quiz

If any question surprised you, go back to the notes and re-read that section slowly. The questions above test the exact distinctions that trip up beginners the most — particularly the DOM vs HTML source, HTTPS vs trustworthy, and semantic HTML vs visual appearance.

  • The internet is the road. The web is one service using those roads.
  • HTML labels content. CSS styles it. JavaScript makes it behave. Each has exactly one job.
  • The DOM is a live memory object — not your file on disk.
  • Semantic HTML is an ethical responsibility, not just a best practice.
  • Performance-critical animations belong on transform and opacity, not layout properties.
If the browser builds the DOM from HTML, and JavaScript can change the DOM without changing the HTML file —
